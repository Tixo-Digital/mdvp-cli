# Code of Conduct

MDVP contributors are expected to keep project discussion practical, respectful, and focused on improving the public CLI and protocol surface.

## Expected Behavior

- Be direct without being hostile.
- Assume public discussions are durable and searchable.
- Keep critiques tied to code, docs, reproducible behavior, or user impact.
- Respect maintainer scope decisions, especially around private infrastructure, billing, and datasets.
- Do not post secrets, private screenshots, customer data, or exploit details publicly.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language.
- Publishing private credentials, private user data, or non-public crawl output.
- Pressuring maintainers to expose private infrastructure or production resources.
- Repeated off-topic comments after a maintainer has redirected the discussion.

## Enforcement

Maintainers may hide or delete harmful content, lock threads, block accounts, or move sensitive reports to a private channel. Security issues should follow `SECURITY.md`.
